처리 목적과 범위

선택한 게시물의 키워드 댓글에 영어 안내와 Click 버튼을 보내고, Click 또는 대소문자를 구분하지 않는 READY 답장을 받은 뒤 팔로우 여부를 확인해 해당 설정의 Notion 링크를 전달합니다. 자동 발송은 켜져 있는 동안 선택한 1~10개 게시물에 적용됩니다. 계정 전체 발송 시도는 최근 24시간 기준으로 설정한 10·25·100회 상한을 따르며, 거절되거나 결과가 불명확한 시도도 포함됩니다. 여러 게시물에서 같은 수신자의 READY 대기 세션이 겹치면 모호한 READY는 처리하지 않고 Click으로 구분합니다. 과거 대화 전체나 무관한 게시물·메시지는 검색하거나 처리하지 않습니다.

연결 정보를 저장할 때 Meta에서 계정 식별번호와 사용자 이름을 확인합니다. 자동 발송을 켜거나 저장된 실행을 재개할 때는 계정과 최근 게시물 최대 50개의 식별번호·주소·유형을 다시 확인할 수 있습니다. 실행 중에는 선택한 게시물의 댓글 작성자와 대상 계정의 팔로우 상태를 확인하고 메시지를 전송할 수 있습니다. 댓글 작성자는 해당 댓글 API 응답으로 확인하며 댓글 ID에서 추정하지 않습니다.

웹훅과 저장 정보

수신 웹훅은 앱 시크릿으로 서명을 확인한 뒤 처리합니다. 원문 HTTP 본문과 서명은 파일이나 로그에 기록하지 않습니다. 선택한 댓글과 확인된 메시지를 처리할 때 필요한 정규화된 이벤트 필드와 본문은 같은 런타임 SQLite 데이터베이스에 처리 대기 중 임시 저장될 수 있습니다. 처리·무시·폐기된 이벤트 본문은 지웁니다. 전송 결과가 불명확하면 다시 보내지 않습니다.
