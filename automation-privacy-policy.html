이 안내는 사용자가 선택하고 실행을 승인한 Instagram 댓글·DM 자동화에 적용됩니다. 실행 전 게시할 안내와 설정을 확인하고 별도로 시작해야 합니다. 화면을 열거나 설정을 저장하는 것만으로는 Meta 요청, 웹훅 수신 또는 DM 발송이 없습니다. 운영자가 연결 준비에 동의하면 계정·게시물을 조회하고 콜백 인증용 수신기를 열며, DM은 별도로 시작한 뒤에만 처리합니다.

처리 목적과 범위

선택한 게시물의 키워드 댓글에 영어 안내와 Click 버튼을 보내고, Click 또는 대소문자를 구분하지 않는 READY 답장을 받은 뒤 팔로우 여부를 확인해 해당 설정의 Notion 링크를 전달합니다. 실행은 선택한 1~10개 게시물과 선택한 최대 60분의 로컬 자동 발송 실행이며 발송 시도 상한을 설정합니다. 여러 선택 게시물에서 같은 수신자의 READY 대기 세션이 겹치면 모호한 READY는 처리하지 않으며 Click으로 구분해야 합니다. 계정 전체의 과거 대화를 검색하거나 무관한 게시물·메시지를 처리하지 않습니다.

준비 단계에서는 Meta에서 계정 식별번호·사용자 이름과 최근 게시물 최대 50개의 식별번호·주소·유형을 조회합니다. 실행 중에는 선택한 게시물의 댓글 작성자 확인, 대상 계정의 팔로우 상태 확인 및 DM 발송을 요청할 수 있습니다. 댓글 작성자는 해당 댓글 API 응답으로 확인합니다. 작성자 식별번호를 댓글 ID에서 추정하지 않습니다.

웹훅과 로컬 기록

수신 웹훅은 앱 시크릿으로 서명을 확인한 뒤 처리합니다. 원문 요청 본문과 서명은 디스크에 기록하지 않습니다. 선택한 게시물의 키워드 댓글, 확인 대상으로 제한된 READY 메시지와 현재 세션에 맞는 Click 이벤트만 정규화해 새 런타임 SQLite에 처리 대기 중 저장될 수 있습니다. 처리 완료·무시·폐기 때 대기 본문을 지우며, 처리하지 못한 대기 본문은 수신 후 48시간 기준으로 명시적 정리 대상이 됩니다. 진행 중 작업은 정리에서 보호합니다.

실행 기록에는 선택 설정의 버전, 확인된 계정·게시물·댓글·수신자 식별번호, 이벤트 및 메시지 중복 방지 정보, 처리 상태·시각, 팔로우 확인 결과와 발송 시도가 포함될 수 있습니다. 재전송 방지를 위해 메시지 ID와 발송 상태를 보관할 수 있습니다. 전송 결과가 불명확하면 재발송하지 않습니다. 앱 시크릿 원문·액세스 토큰·확인 문자열은 파일·DB·일반 로그에 저장하지 않으며, 앱 시크릿의 도메인 분리 지문은 재시작 시 저장소 범위를 확인하기 위해 남을 수 있습니다.

보관과 삭제

대기 본문은 처리·폐기 때 지우고, 미처리 본문은 운영자가 정리 작업을 실행할 때 수신 후 48시간 기준으로 논리 삭제합니다. 종료된 실행의 기록은 예정 종료 시각부터 90일을 기준으로 명시적 정리 대상이 됩니다. 일찍 중지한 경우 예정 종료 시각은 실제 중지보다 최대 60분 늦을 수 있습니다. 정리는 자동으로 실행되지 않으며, 운영자가 화면의 정리 기능을 명시적으로 실행해야 합니다. 삭제는 데이터베이스의 논리 삭제이며 백업이나 저장장치의 모든 사본이 물리적으로 지워진다고 보장하지 않습니다.

외부 서비스

Meta/Instagram은 계정·게시물·댓글·팔로우 조회와 메시지 전송을 처리합니다. 임시 Cloudflare HTTPS 터널이 연결되면 웹훅 및 통신 메타데이터가 터널을 통과할 수 있습니다. 관리 화면은 로컬에서만 제공하고 터널에 연결하지 않습니다. GitHub Pages는 이 안내 페이지 방문을, Notion은 사용자가 링크를 열 때의 방문을 자체 정책에 따라 처리할 수 있습니다. 이 앱은 Notion 방문을 별도로 추적하지 않습니다.
